**Item 1 — REJECTED 9/9.** Not one seat found a conditions path. Common core: a press release
is ONE voice (the issuer) regardless of syndication; counting it as independent breadth is
score inflation by construction, violates §15 "no aggregators" + Mainstream v2, and creates a
PURCHASABLE inflation vector (any micro-cap can buy M-breadth for a wire fee). Executioner
adds the mechanical kill: `_news_write` forces mainstream tier, damaging the early read. The
rejection is minuted so the question is not re-asked.

**Item 2 — Conditionally approved 9/9 (Executioner: SHIP-LATER).** The right philosophical
home: an issuer event is a STIMULUS/displacement, honestly labeled — never breadth. Binding
conditions across memos, deduplicated:
1. Never `_news_write`; structural non-breadth routing (Economist: enforce in code, not convention).
2. **Honest provenance class "issuer-primary"** — NOT the expert tier: expert's single-source
   scoring exemption must never attach to self-issued PR (Guardian + Challenger, hardest flag).
3. Cluster-over-singleton weighting: one promoter is noise; 40 same-class announcements in a
   window is a displacement (Economist).
4. Pre-registration BEFORE accumulation: event classes declared in writing, ≥60–90d held-out,
   ≥50 resolved events per class, cohort comparison metric pre-declared (Statistician + Forecaster).
5. PR-headline extractor must pass §16 FORMAT gate on a live sample first — unproven today;
   promotional boilerplate is a new failure surface vs editorial titles (Executioner).
6. Novelty measurement: % of triggered topics not already in-system ±24h; <~30% novel → drop
   (Operator). Promotional-junk gate assuming adversarial issuers (Outsider, Challenger).
7. Score by lead-time distribution, not hit rate — a PR "win" with zero lead is the
   announcement scoring itself (Forecaster; Challenger's "we detected the press release" attack).

**Item 3 — Conditionally approved 9/9 — the unanimous strongest item.** Priced capital events
(offering/convert/placement/ATM/buyback) are primary capital-structure FACTS with dollar
amounts — money data under C5/C6, and the issuer's promotional incentive contaminates its
adjectives, not its filed numbers. Binding conditions, deduplicated:
1. Held-out accumulation FIRST (flag-gated, own table, zero scoring imports); backtest-before-
   ship for any score wiring — separate future decision (all seats; Executioner's ship steps).
2. **Seal the class→direction taxonomy + resolution window + resolution source (market-ledger
   realized EOD direction, no-lookahead) in writing BEFORE the first row accumulates** —
   else the backtest is fit, not tested (Forecaster).
3. **Announced ≠ priced ≠ closed** — three states in the schema from day one; only
   priced/closed with stated amounts approach the money pathway; announced dollars are never
   moved dollars (Challenger, Economist, Guardian).
4. Verify per-ticker feed access + density for ALL mapped tickers, not just AAPL; "not covered
   by source" stored distinct from "no events" (Challenger, Statistician).
5. Classifier precision hand-audit (≥95% on a ≥100–200 labeled sample) before stored classes
   are trusted; classification is OURS from titles only — never StockTitan's AI summaries
   (Statistician, Outsider, Guardian).
6. **EDGAR/wire-direct comparator + fallback**: measure StockTitan's latency/coverage edge vs
   the primary source over ≥100 events; if none, skip the middleman; either way StockTitan may
   never be the ONLY tap (Operator S1 — the common-mode dependency rule; Outsider's
   point-blank question).
7. Accumulation floor WRITTEN NOW: ≥90 days / ~200 classified priced-closed events before any
   wiring proposal — a fortnight of data cannot quietly satisfy the gate (Challenger, Statistician).
8. Per-class, per-scope accuracy only — micro-cap/OTC cohort never blended into watchlist
   figures or the headline ledger rate (Statistician, Operator S4); backtest measures
   INCREMENTAL value over FMP/Finviz (Challenger).
9. No per-share/dilution-% derivations (no shares data — fabrication boundary, Economist);
   currency as a first-class schema field (Expansionist); §16a cold-start for any new tickers;
   dates only via `gate_date()`.

**Item 4 — Consensus: per-ticker targeted pulls are the production mode** (complete by
construction for the declared watchlist; batch-paced ~35 keyless requests/cycle). The 6h
firehose sample is NOT "⅓ coverage" but volume-correlated censoring — it under-samples burst
periods, the exact moments that matter; it may never feed any score, baseline, coverage claim,
ledger enrollment, or published statistic (strongest: Guardian, Forecaster — censoring deletes
first crossings BEFORE sealing, corrupting the honest denominator upstream). If retained for
discovery only: every derived row stamped sampled + measured capture fraction.

## DISAGREEMENTS (signal, not smoothed)

1. **Push-hub (WebSub/superfeedr).** Expansionist wants it PILOTED as the only 100×-viable
   architecture ("whoever builds that muscle onboards the next 20 feeds free"). Executioner
   CUTS it outright (new always-on public callback surface, silent-death failure class, buys
   nothing at 6h cadence + 365d patience). Operator/Outsider land between: defer behind a
   measured trigger (per-ticker miss-count > 0 / a proven quarter). Statistician/Forecaster:
   permissible but only through its own §16 gates with delivery-completeness measurement.
2. **Firehose for Item 2's cluster detection.** Executioner tolerates a SAMPLED trigger feed
   (a missed item is a missed trigger, not corrupted data) if registered as sampled;
   Guardian/Forecaster/Statistician reject firehose-derived anything near measurement;
   Economist allows it only with per-poll measured capture rates and an eventual shorter
   interval or push cutover.
3. **Item 2 promotion path.** Most seats: conditions on the same build. Executioner uniquely
   sequences it BEHIND Item 3 (2–4 weeks of classifier evidence first). Operator uniquely
   demands a novelty-rate threshold as the go/no-go.
4. **EDGAR-vs-StockTitan primacy.** Operator offers EDGAR-only as a live option (b) (skip the
   middleman entirely); Outsider leans EDGAR-as-source-of-record with StockTitan as fast alert
   layer; other seats accept StockTitan-primary with the comparator/fallback condition.
5. **Sample sufficiency.** Challenger/Statistician/Outsider hard-require a ≥2-week
   re-measurement before ANY pack figure is quoted anywhere (N=1 day today); other seats fold
   this into general conditions.
