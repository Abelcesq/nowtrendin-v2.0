# ATTENTION-FLOW DIVERGENCE DETECTOR — PRE-REGISTERED DESIGN (C8)
**Date:** 2026-08-05 PT · **Status: DESIGN ONLY — build gated on the CRYPTO_ETF_FLOW flip
+ ≥30 trading days of live measured flow.** Committed BEFORE any threshold has met any
data; changing these terms after data exists is a new registration.

## What it measures (Kindleberger's instrument, in the founder's canon)
The divergence between the platform's two measured axes for an asset: ATTENTION HEAT (the
coin's topic Gradient-Score inputs, externally collected) vs MEASURED MONEY FLOW (the fund
share-flow leg + insider panel where applicable). The canonical distribution signature —
attention still expanding while measured money is flat or leaving — becomes a MEASURED
FLAG, never a call.

## Pre-registered terms
1. **Coverage gate (structural):** the detector renders ONLY where flow is MEASURABLE —
   `absence_class` must be absent/none (BTC/ETH/SOL/XRP post-flip). On structurally-blind
   coins the signature is instrument blindness and is never rendered (board 6/6).
2. **Divergence definition:** attention percentile (vs the coin-topic's own trailing
   baseline) minus flow percentile (vs the coin's own flow baseline), both over the same
   trailing window. Windows/percentile floors are read off ≥30 trading days of live flow
   data via the same formula-first / numbers-off-the-study method as the vote floors — the
   FORM is registered now; the numbers are minted from the study, not tuned to outcomes.
3. **Nulls (Malkiel), registered now:** (A) divergence computed with the flow axis replaced
   by the coin's own 7-day momentum sign; (B) persistence (yesterday's divergence). The
   detector's ledger reports beside both; the word "signal" is earned only by beating (A).
4. **Its own ledger row type** before anything score-adjacent: flag date, divergence value,
   realized outcome window, verdict — held-out, n≥30 publication floor, F8-style
   unconditional base rate served beside any rate.
5. **Language:** "attention-flow divergence measured for N days" — never "mania", never
   "bubble", never a warning-to-act. The alert asymmetry (false-alarm vs silent-miss cost)
   is declared in the build doc BEFORE the first alert (Taleb).
6. **No blending:** the two axes are never combined into any served score; N never enters.
